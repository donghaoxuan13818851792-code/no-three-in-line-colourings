# G11 evidence

This directory contains the computational evidence for excluding a six-colouring of the \(11\times11\) grid.

- `R/` — profiles with at least two size-22 classes.
- `Q/` — profiles with exactly one size-22 class.
- `P/` — profiles with no size-22 class.
- `catalogues/` — catalogue definitions, frozen metadata and compact inputs.

Each branch directory should eventually contain a branch README, frozen manifest, source or pointers to source, terminal ledger/certificates, and verification instructions.
