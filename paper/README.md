# Preprint

This directory contains the public preprint of **The arc chromatic number of square grids** by Jason Dong, Matthew Lewis, Ivet Lobo, Thomas Prellberg and Ian Wanless.

- `preprint.pdf` is the 28-page preprint dated 22 September 2026.
- `arxiv.tex` is the source version identified in the authors' source bundle as the version uploaded to arXiv on 20 September 2026.

The displayed date in the PDF is frozen to 22 September 2026 to match the author-circulated preprint. The mathematical source is otherwise the arXiv submission source.
